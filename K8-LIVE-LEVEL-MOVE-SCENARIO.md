# К8 — проверка переноса тела на другой слой

Статус: подготовлено; установка и изменение модели ещё не разрешены.

Проверяется уже открытая собственная тестовая модель
`Working_7b0765448a714a97a8f78edf46754834`. В ней одно тело с именем `1`,
которое находится на слое `0: General`. Цель — существующий видимый слой
`1: Surfaces`. Создавать или переименовывать слой не требуется.

## Что произойдёт после отдельного разрешения

1. Будет создана резервная копия установленного Bridge. Подготовленный пакет
   обновит Bridge с `0.33.5-dev` до `0.34.7-dev`, панель перезапустится один раз.
2. Новый C# MCP host `0.40.0-dev` заново прочитает модель, тело, слои и открытые
   документы. Уже открытую тестовую копию он подтвердит без повторного открытия.
3. Будет подготовлен план переноса только тела `1` с General на Surfaces.
4. После проверки плана будет выполнен один перенос. PowerShape при этом
   снимает выделение; это ожидаемое действие API.
5. Отдельное чтение проверит новый слой тела, прежние положение и доступные
   геометрические свойства, остальные слои, семь открытых окон и файлы источников.

Сохранение модели и повторное открытие в этот сценарий не входят. Если результат
переноса неизвестен, команда не повторяется и перенос обратно не выполняется:
сохраняются исходный запрос и журнал для независимой проверки.

## Что сможет проверить пользователь

- На панель установлен новый Bridge, резервная копия указана в отчёте установки.
- Тело `1` находится на слое Surfaces; его положение и форма визуально прежние.
- Выделение снято. Слой Surfaces остался видимым.
- Отчёт отдельно показывает результат команды и результат независимого чтения.
  Эти наблюдения не объявляются доказательством полной топологической идентичности.
