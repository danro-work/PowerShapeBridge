# Сохранённый результат переноса двух поверхностей

27 октября 2026 технически проверен полный путь нового numerical-normal набора:
новый SaveAs → отдельная проверка → защищённый seed и checkpoint → закрытие
собственного writer → отдельная проверка → открытие новой собственной копии
из seed → отдельная проверка → public-чтение всех шести поверхностей.

До этого новый набор последовательно переносил поверхности «2» и «3» на
WORLD [0,1,0] мм. Ранее отдельно изменённая «1» и поверхности «4»–«6» служат
контролем. Геометрические команды в блоке сохранения не повторялись. Старый
частично остановленный intent остаётся отдельным историческим unknown со
своими исходными claim/журналом/архивом; успех нового intent его не переписывает.

На четырёх стадиях — до SaveAs, после него, перед закрытием и после открытия —
public getters вернули точное совпадение 72 точек и нормалей всех шести
поверхностей, array layout и visibility. Состав, слои, WORLD и пустое выделение
сохранились. Сопоставление после открытия использует проверенный тип/имя и
геометрические свидетельства, не предполагает постоянство native ID.

Собственный Result находился в окне 27 из 28. Новый
[профиль упорядоченной финализации](ORDERED-SAVED-FINALIZATION.md) закрыл только
его. Отдельный verifier подтвердил точные логические идентичности и порядок
остальных 27 документов. Последующее открытие вернуло число окон к 28;
оба экземпляра PowerShape сохранены.

Writer изменил сериализованные байты при закрытии, сохранив физическую
идентичность. Это разрешённое изменение собственного файла отдельно записано;
защищённые seed/checkpoint и заранее подготовленная неоткрытая копия остались
побайтно прежними. Независимый OS-аудит проверил шесть физических файлов,
повторные хеши, три цепочки журналов SaveAs/close/OPEN, отдельные verifiers,
claims и 1630 защищённых файлов с единственным разрешённым изменением writer.
Изменение runtime при установке предварительно сверено с точным deployment
plan и резервом, отдельно от CAD-файлов; исходные карты хешей сохранены.

Native0.71 установлен с резервом; stagedSDK0.77 прошёл реальный STDIO-сценарий.
Постоянный SDK0.48 не переключался. Обычный readonly затем подтвердил Native71,
основной процесс, открытую собственную копию, шесть SURFACE, WORLD и пустое
выделение. Полная регрессия после реального блока:1180 из1181, без пропусков. Один старый
control с секундным тайм-аутом отказал под общей нагрузкой; те же два неизменённых
варианта отдельно прошли2/2. Исходный failed TRX сохранён; это не полностью
зелёный общий прогон. Кода исполнения и тайм-аутов ради успеха не меняли.

Это доказательство измеренной сохранности конкретного набора. Полная топология,
прочие типы/наборы/параметры, все пять приёмочных классов и К8–К11 ещё открыты.
Личная приёмка пользователя P0 остаётся отдельной контрольной точкой.
