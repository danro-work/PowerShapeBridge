# Disposition of an observed partial SURFACE set

This full-mode experimental route stops an old strict set intent permanently while
preserving its original `outcome_unknown`, claim, journal and first-step records.
It does not repeat, reverse or continue a geometry command. General MCP v1 and K11
remain subject to their separate acceptance criteria.

The separate `surfaceSetStopDispositionExperimental` flag defaults to false and
requires the passive partial-stop observer and its original guarded dependencies.
The read-only server never exposes these tools.

1. `prepare_surface_set_stop_disposition` binds the original stopped execution,
   immutable qualified passive observation, fresh candidate/listing, all current
   surface samples and source/checkpoint/working bytes. It freezes an expiring
   packet and issues one connection-local disposition handle.
2. `execute_surface_set_stop_disposition` consumes that handle before submission,
   rechecks current context, and creates a separate claim/journal/recovery fence.
   It copies the exact original fence bytes to the fixed archive. The original
   standard mutation fence stays active throughout this unverified state.
3. `verify_surface_set_stop_disposition` requires new inspection and listing after
   the archive return. It independently checks the archive, both matching fences,
   old immutable history, all samples and files/windows. Only qualified retained
   COM verification can record `abandoned_partial_observed` and release the two
   matching fences. A fake provider cannot release them.

The SDK independently checks the original Native receipts, immutable plans, claims,
journals, archive and resolution before issuing bounded current copy/binding leases.
Those leases are observations; a new geometry operation requires a separately
prepared new intent. The old set never becomes successful or replayable.

Historical loading from an archive is explicit and tied to the checked new
disposition plan/claim/resolution. Default passive stop inspection still requires
the active original fence; it cannot silently search for an archive.

An unknown archive, verification or release result stops without retry, inverse,
cleanup or automatic fence restoration. Inspect the recorded artifacts first.
Surface samples establish bounded current observations, not full topology identity
or saved/reopened persistence.

Targeted qualification: `verify-surface-set-stop-disposition.ps1`, SDK catalog/gate
tests and actual Framework-to-SDK receipt checks. Fake terminal artifacts are
created only inside an explicitly marked synthetic root, never the live runtime.
