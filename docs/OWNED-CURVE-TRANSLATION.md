# Owned COMPCURVE translation

Native 0.58 / staged SDK 0.64 add `execute_owned_curve_translation` and
`verify_owned_curve_translation`. Both are full-server only, behind the separate
default-false `ownedCurveTranslationsExperimental` flag. It requires the existing
owned-translation and passive-curve-layout flags. Ordinary Codex SDK48 is unchanged.

The bounded profile is exactly one explicitly targeted COMPCURVE plus one unchanged
SOLID control in an owned, idle WORLD/mm/factor1 copy with empty selection. The
original disabled `translate_entities` plan, exact observed entity set and owned
document binding remain authoritative. Name and native ID are distinct fields.
There is one direct `TranslateItem`; no selection, save, inverse or command replay.

The versioned `owned_compcurve_controls_translation_v1` witness uses the actual
PowerShape 2023 getter layout qualified by the [passive reader](CURVE-LAYOUT-QUALIFICATION.md):
positions and before/after tangent directions `[N,3]`, magnitudes and Boolean free
flags `[N]`, all native lower bounds 1. Caller supplies the complete explicit range
`1..N`, bounded 2..32; a held passive `POINT.NUMBER` getter independently confirms
the count. This does not change the old flat/3*N `RotationMeasurements.Curve` adapter.

Every target control position and observed min/max range must move by the declared
WORLD vector within 1e-6 document raw mm per component. Directions, magnitudes,
flags, count, layout, identity and other observed properties must remain equal.
The SOLID is checked using eight face names/UVs pinned before the command, their
positions and normals, COG, native WORLD bounds and available raw invariants.
The same descriptor is reused after translation; witnesses are not reselected.
These controls do not certify complete continuous geometry or topology. Curve
areaRaw has unresolved units and is not described as mm². No bounds are fabricated.

This strategy runs inside the existing `OwnedTranslation` executor and held COM
context, with schema4 frozen intent, the original operation-plan once claim,
matching copy fence and six-state journal. Original lease, saved files and all
windows are rechecked; at least 90 seconds of original lease must remain immediately
before execution. Successful return remains executed_unverified until the separate
fresh verifier completes the original journal and releases only its matching fence.
SDK independently checks original bytes/SHA, plan dependencies, typed measurements,
claim/journal chain and the affine postcondition. Unknown outcomes retain evidence
and cannot trigger retry, inverse or fence repair.

On 26 October one WORLD `[1,2,3]` mm translation passed through actual SDK STDIO,
the single installed worker, a separate verifier and an additional passive getter.
Independent Python checked all four square control positions with zero component
error, eight tangent directions/magnitudes, sixteen free flags, and the unchanged
SOLID samples/COG/bounds/raw metrics. All 695 protected pins and 28 windows were
preserved after accounting for the authorized backed-up deployment. Ordinary
read-only Codex confirmed the same owned copy and empty WORLD separately.

The first scenario preflight stopped after two passive reads because its declared
SOLID native ID confused name `1` with ID `5`; both original and prior observations
confirmed ID5. The retained corrected scenario submitted the only translation.
No new OPEN, SaveAs, close, selection or mouse interaction occurred in this block.
The translated geometry is **not saved**; persistence is a separate next block.
Other curve types, mixed target sets, curve rotation/scale, the full K8 matrix,
K9, five-class K10 and release/personal K11 remain open.
