# Owned SURFACE uniform scale (experimental)

Native0.56/stagedSDK0.62 add three full-only tools behind the separate default-false
`ownedSurfaceScalesExperimental` flag. Read-only retains passive getters; the Python
compatibility facade does not expose the new execution recipes. Existing SOLID
scale defaults, schemas, measurement and restore restrictions are retained.

Prepare an explicit one-SURFACE entity set, `prepare_uniform_scale_plan`, fresh
owned binding, then `prepare_owned_surface_scale` with a known explicit UV grid.
`execute_owned_surface_scale` consumes its intent and CAD leases before IPC;
`verify_owned_surface_scale` requires the original execution ID/SHA and fresh
candidate/active document choices. Preparation issues no geometry command.

The bounded profile supports one uniquely named SURFACE among1..8SURFACEs in an
owned mm/factor1 document, WORLD and empty selection. Factor0.01..100 except1,
an explicit bounded WORLD centre and grid divisions1..4 are required. The witness
profile is `surface_uniform_scale_explicit_uv_v1`; no UV-domain inference occurs.

The shared existing scale lifecycle uses a typed SURFACE variant of its fixed
13-phase NOKEEP program. A held COM context validates process/document/selection
between phases. All phases must return successfully; execution alone remains
unverified and fenced. Independent verification checks the original phase hash
chain, once claim, journal, files and fresh observed geometry. An unknown stops
without automatic replay, inverse, CANCEL, DISMISS or clear. The original lease
must have at least120seconds before execution; it is not extended.

Target points must follow centre + factor*(point-centre), within2e-6mm per
component. Positive-scale normal directions must be preserved within2e-6 per
normalized component. Target raw area follows factor squared; its unit is not
assumed to be mm². All other grids, visibility, array layouts, identities and
observed properties remain exact. Native bounds are unavailable. Reparameterized
surfaces are rejected by this explicit-UV profile; sampled checks do not establish
continuous-surface or full topology equivalence.

Registration uses the existing `.WithTools(ToolCatalog.Create(session))` and
`..SurfaceScaleTools.Create(session)`. MCP packages stay pinned to2.2.0/.NET10;
there is no transport or package-version migration.
