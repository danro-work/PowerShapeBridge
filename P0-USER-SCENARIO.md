# P0 — пользовательский сценарий

Публичная версия. Согласованный проход технически завершён через обычный Codex, пользовательская приёмка ожидается. **Команды завершённого прохода не повторять.** Точные пути, хеши, параметры экземпляра, исходные request IDs и доказательства доступны только локально: work/P0-local-state-20261017.md и evidence/P0-user-model-20261016a/.

## Границы

Пользователь выбирает сохранённый `.psmodel` (далее USER_MODEL.psmodel). Исходник защищён; изменяется только собственная рабочая копия и отдельный новый результат. Поддержан один явно определённый SOLID, WORLD и подтверждённые миллиметры. При нескольких телах — остановка до переноса и явный выбор. Измерения не являются доказательством полной топологии.

## Проверенное подключение

Native 0.37.0-dev и SDK 0.43.0-dev. Основной powershape_bridge разрешает 28 инструментов P0 и чтения; отдельный powershape_bridge_readonly запускается с --read-only и содержит 8 инструментов без изменения CAD. Шаблон: config/p0-codex-example.toml; машинные пути задаются локально. Настройка применяется только после согласия, с полным резервом и проверкой остальных полей; затем подтверждаются фактически загруженные версии/каталоги и живое чтение.

Уже действующая настройка проверена; повторного применения не требуется. Полный резерв, receipt и безопасный возврат доступны в локальном комплекте. Возврат отказывается затереть более поздние изменения настройки; переподключение MCP не отменяет CAD-действия. Native-панель для подключения не перезапускается.

## Одна согласованная последовательность

1. Свежие процесс/сеанс/документ/число окон, свободная очередь и хеш сохранённого источника. Подготовить собственные working, seed/checkpoint и проверить владение/физическую независимость файлов.
2. Один раз открыть начальную собственную копию, отдельно проверить её активность и состав. Исходник не открывать для изменения. Прочитать единицы, WORLD, выделение и свойства тел.
3. Единственный поддержанный SOLID включить в явный набор; при неоднозначности или неподдержанных единицах/свойствах остановиться до команды. Для утверждённого P0 вектор WORLD [+1,+2,+3] мм, исходное выделение пустое и WORLD активна. Контекст не исправлять автоматически.
4. Выполнить один перенос. Отдельно проверить смещение габаритов/доступного COG и сохранность остальных доступных свойств, состава, слоёв и систем. Недоступные свойства и raw-единицы указать явно.
5. Только после успеха — один SaveAs в подготовленный НОВЫЙ файл. Отдельно проверить журнал, файл и сохранность источника/checkpoint; перезаписи нет.
6. Подготовить отдельную копию сохранённого результата, один раз открыть её, отдельно проверить новые ссылки/привязку и сохранность изменений. Оставить собственную копию результата активной и предъявить локальные пути и отчёт пользователю.

Окна: N → N+1 после начального OPEN → N+2 после копии результата. N читается перед запуском; неожиданные окна или чужая активная модель останавливают сценарий. Старые окна не закрываются/не сохраняются. Мышь этим сценарием не разрешена, вторая панель/worker не запускается.

При неизвестном исходе — журнал и независимое чтение; нет retry, inverse, Undo, дополнительного SaveAs/OPEN или очистки по догадке. Новая попытка не маскируется под проверку старой.

## Подтверждённый результат и приёмка

Все четыре действия прошли по одному разу с отдельной проверкой до следующего. Новый файл и открытая копия сохраняют перенос; исходник и 199 защищённых файлов прежние. Подтверждены обычный SDK, отдельное чтение, прямой пассивный Native и файловый аудит. Точный экземпляр отчёта остаётся локальным. Пользователь осматривает результат и принимает P0; только затем начинается расширение К8–К11.

Короткая инструкция: [P0-QUICKSTART.md](docs/P0-QUICKSTART.md). P0 не заменяет приёмку универсального v1.
