# P2.24 — наборы сущностей, экспериментальный блок кода

9 октября 2026. Общий MCP v1 ещё не завершён; последняя живая квалификация P2.22.

Реализованы отдельные кандидаты, подготовка неизменяемого наблюдаемого набора и
повторная проверка набора в worker. P2.21 read references не принимаются.
Поддержаны кандидаты SOLID/SURFACE/COMPCURVE, явный документ, SHA нативного ответа
и файла набора, срок, нативный инвентарь/свойства/контекст. Никаких CAD-мутаций.
Функции доступны только по entitySetsExperimental=true в общем профиле.

Сборка 0.24.0: `work/P2.24-sets`; конфигурация: `config/general-entity-sets.json`.
Обычный общий профиль не включает эксперимент. Контракт: ENTITY-SETS.md.
build.ps1/deploy-current.ps1 дополнены зависимостями, deploy-current не запускался.
Прежний deploy-current сохраняет квалификационную runtime-конфигурацию и не является
готовой установкой нового общего профиля.

Проверки: 129 C#, 35 Python, MCP-протокол; все прошли. Проверки нового блока
не подключаются к CAD. Доказательства/хеши: evidence/P2.24-sets/code-verification.json.
Воспроизведение: build.ps1 -OutputDirectory work/P2.24-sets -ConfigurationPath
config/general-entity-sets.json; затем verify-entity-sets.ps1.

Свежим чтением установленного MCP подтверждены три открытых документа, активный
Test_Block_P2 и worker 0.22.0. Незавершённая runtime-очередь при проверке пуста,
одна панель и один PowerShape; это не постоянные PID/ссылки. Результаты чтения
сохранены отдельно. Runtime и CAD не менялись; мышь не использовалась.

Ограничения: живая квалификация общего профиля и новых наборов ещё не выполнена.
Standalone validation не авторизует последующий CAD-edit. Probe освобождает COM
контекст; перед будущей командой нужен повторный guard в её исполнителе. Полная
топология, постоянная идентичность/все сценарии переоткрытия, двухнаборные ограничения
и общие геометрические операции не приняты. Raw-единицы не нормализуются без проверки.

Следующий блок: подготовить проверяемое развёртывание общего профиля в единственной
пользовательской панели, квалифицировать чтение/наборы и отказы без изменения CAD;
затем интегрировать guard в общий план/исполнитель и принимать параметры/постусловия
операций только на собственных рабочих копиях. Служебный запуск с COM 0x800401E3
не повторять как диагностический цикл. Технологический модуль остаётся следующим продуктом.
