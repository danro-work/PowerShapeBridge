# Результат проверки P1, 7 октября 2026

Подтверждено выполнение двух последовательных запросов model.snapshot в обычном пользовательском Windows-сеансе через файловую очередь. Повторный запрос отправлен из Codex без нажатия кнопки пользователем; ответ получен. Это локальный канал запросов чтения, не MCP.

Продукт: PowerShape 23.2.2, native version 23202, PID 41000. Модель: Test_Block.psmodel, native model ID 280000099. Один SOLID, native ID 5, слой 0 General. Единицы длины mm. Общий допуск модели 0,01; он не является гарантией точности проверки.

Прочитано: 6 поверхностей, CLOSED=1, CONNECTED=1, WATERTIGHT=1, TRIMMING_VALID=1, NLINKS_OPEN=0, COG=[0,0,10], AREA=2400, MAXIMUM_EDGE_TOL=0,00001. Эти признаки не заменяют независимую приемку геометрии.

Независимое чтение STEP: восемь вершин и шесть плоских граней; габариты вершин 20×20×20, единицы mm. Для данного блока ожидаемый объем 8000 мм³ и площадь 2400 мм². Общий алгоритм точных BRep-габаритов этим чтением не реализован.

Неопределенность: SOLID.VOLUME вернул 0,8. Единицы/масштаб этого значения пока не квалифицированы; не трактовать как 0,8 мм³ и не вводить коэффициент 10000 по единственному образцу. Поле volume в JSON P1 является сырым результатом API; qualification сообщает, что точность не подтверждена. Следующая версия должна явно обозначать volumeRaw и подтвержденные единицы отдельно.

Исходные файлы до/после имеют одинаковые SHA-256, selection count=1 и active workplane=0 совпали. Это не доказательство неизменности полного selection или всей несохраненной геометрии. Изменяющие команды отсутствуют.

Отчеты: responses/ebccbc8b82c84838b754e541c6d13f0a.json и responses/5df76b749b9545a581cd36d1981587f8.json в releases/P1. Запуск GUI, файловый транспорт и чтение инвентаря подтверждены.
