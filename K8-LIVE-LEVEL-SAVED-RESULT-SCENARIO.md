# К8 — проверка сохранённого результата переноса

Статус: выполнен15октября2026 по прямому разрешению пользователя.
Один SaveAs и один OPEN подтверждены независимо; разрешение использовано.
Результат: STATUS-K8-LEVEL-SAVED-RESULT.md. Ниже исходный согласованный сценарий.
Исполнитель: `work/qualify-live-level-saved-result.py`, по умолчанию только чтение.
Установленный Bridge 0.34.8; изолированный SDK 0.40.1. Установка и перезапуск не нужны.

Исходное состояние: собственная открытая
`Working_7b0765448a714a97a8f78edf46754834`, одно тело «1», Surfaces(1),
пустое выделение, мировая система координат, семь окон. Реальный перенос уже
выполнен ровно один раз и повторяться не будет. Его журнал/claim защищены.

Предлагаемая проверка:

1. Свежим чтением проверить процесс, активную модель, тело/слой/выделение,
   семь окон и защищённые файлы. Подтвердить принадлежность уже открытой копии
   по исходному OPEN; нового открытия на этом шаге нет.
2. Подготовить новый уникальный `savedresults/<id>/Result_<id>.psmodel`.
   Один SaveAs текущей тестовой модели; исходный working-файл не перезаписывать.
   Активный документ получит новый путь/имя, его ID может измениться.
3. Отдельно проверить исход SaveAs и сохранённые байты. При неизвестном исходе
   остановиться, сохранить журнал/fence, не повторять SaveAs.
4. Создать новую принадлежащую испытанию копию сохранённого результата и
   отдельный checkpoint; выполнить ровно один OPEN этой новой копии.
   Новая копия станет активной; ожидается восемь окон вместо семи.
5. Свежими чтениями проверить результат OPEN, единственное тело на Surfaces,
   его тип/имя/измеренные свойства, мировую систему и пустое выделение;
   сверить защищённые файлы, saved result, checkpoint и исходный журнал переноса.

Не предусмотрены новый перенос, изменение геометрии, закрытие окон,
возврат активного документа, screenshot или мышь. Проверка наблюдаемых данных
после сохранения/открытия не доказывает полную топологическую эквивалентность.
Новые сохранённые файлы и открытая тестовая копия останутся для проверки пользователем.
