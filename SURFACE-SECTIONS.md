# Нарезка рабочих поверхностей по исходному слою — P2.18

Правило выбора: `тип = SURFACE` и `слой = исходный рабочий слой`. Нельзя выбирать все объекты слоя: там может находиться предназначенная для передачи ЛСК. Контуры, solids, ЛСК, Z-stop, основания, МЗ и вспомогательные построения не становятся основными объектами пересечения.

Для эталонного испытания четыре боковые поверхности куба назначены слою `1:Vneshnie 0.8`. Крышка и основание сохранены в слое `2:AuxTestCaps`. Геометрия взята из последнего проверенного с диска набора шести поверхностей; верхняя вспомогательная поверхность находится на Z=21, боковые рабочие поверхности заканчиваются на Z=20. Это испытательный набор, а не подготовленная производственная ТМ.

Контуры строятся в мировой XY при h=0,8 мм, Z=0…19,2 мм. Созданные кривые помещаются на физический уровень 101 с именем `1k:Vneshnie 0.8`, отдельно от поверхностей. Все высоты исходного рабочего слоя выдаются одним файлом `1-Vneshnie 0.8.dgk`.

Проверка эталонного сечения допускает одну замкнутую кривую либо несколько открытых кривых, если они покрывают все четыре ребра периметра ровно один раз. Проверяются координаты углов, плоскость, габариты и суммарная длина 80 мм. Это не универсальная проверка произвольных сплайнов и не требование замкнутости всех производственных контуров.

Каждая порция выполняется на отдельной копии ранее закрытого и проверенного файла. Исходники защищаются хешами. Сохранение, закрытие и стабилизация файла обязательны до записи его окончательного хеша. После DGK-импорта проверяются только кривые, все рассчитанные высоты и соответствие периметров. Дополнительно шесть исходных поверхностей проверяются в окончательной модели после повторного открытия: габариты, площади и разделение рабочих/вспомогательных уровней.

`SurfaceSectionJob.cs` содержит исполнение и проверки; `surface_job.py` — последовательный автономный запуск. В MCP 0.18.0 добавлены:

- `prepare_test_surface_job`: создаёт неизменяемый план эталонного задания, проверяя прежний источник; CAD не вызывается.
- `execute_test_surface_job_phase`: одна фаза по `jobId`, SHA плана, имени фазы и индексу. Порядок: setup → slice 0…24 → verify_surfaces → export → import → verify 0…24. Неизвестный результат автоматически не повторяется.

Восстановление и диагностические внутренние рецепты не открыты как произвольный MCP Execute. При ошибке после построения можно независимо прочитать уже созданные кривые; восстановление не должно повторять пересечение. При успешном изменении слоя PowerShape иногда кратковременно возвращает прежние/неполные данные — проверяется только чтение с ограниченным ожиданием, без повторного изменения.

Производственные ограничения остаются: исходные рабочие поверхности должны быть уже подготовлены по осям валиков и окончательно масштабированы; исключения NO_SCALE, направления роста/ЛСК, общий слой соседних элементов, очистка коротких кривых и общий допуск отклонения требуют дальнейшей квалификации. Этот прототип не подменяет проверку всей ТМ.

Действующая панель — `releases/P2.6`, worker обновляется отдельно. Заголовок уже открытой панели и корневой исторический PSBridge.exe этим не меняются.
