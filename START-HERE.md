1. Создать локальный проект PowerShape Bridge, основная папка `D:\ChatGPT\PowerShapeBridge\PS_Bridge`. Проверить разрешение записи в неё. Само создание проекта не отменяет sandbox.
2. Скопировать в корень проекта только `PROJECT-STATE.md`, `NEXT-WORK.md` и этот `START-HERE.md`. `AGENTS.md` установить туда при отсутствии существующего файла; иначе объединить. Комплект можно также оставить доступным как дополнительную папку проекта.
3. Не заменять существующие ROADMAP/README/контракты копиями из `reference/`. Это снимки для справки. Не распаковывать архив исходников поверх проекта.
4. Старую папку outputs оставить на месте. `evidence/P2.22/` содержит автономную копию последних доказательств; более ранние этапы доступны по путям PROJECT-STATE.
5. Создать основной чат в локальном проекте и отправить сообщение из `NEW-CHAT-PROMPT.md`. Старый чат сохранить как историю. Не предполагать автоматическую передачу всей переписки.
6. Перед продолжением проверить фактические версии, очередь и подключение без изменения CAD. Не закрывать и не перезапускать PowerShape/Bridge ради переноса.

Комплект подготовлен без изменения исходного приложения, настроек MCP и моделей. Проверки CAD, сборка и развёртывание не запускались.

Локальный Git для исходников рекомендуется отдельным шагом. На момент подготовки каталог `.git` в корне PS_Bridge отсутствовал. Перед инициализацией проверить родительский репозиторий; исключить runtime-бинарники, work, очереди, логи, captures и сгенерированные модели. Нужные эталоны хранить по осознанной политике, не исключать все модели вслепую.
