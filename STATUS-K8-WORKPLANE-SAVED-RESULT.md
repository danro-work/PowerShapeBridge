# К8: система координат сохранена и проверена после открытия копии

Разрешённый сценарий завершён в Autodesk PowerShape 2023 с Bridge 0.35.1-dev
и SDK 0.41.1-dev. Подробные диагностические доказательства сохранены локально.

Обновление с резервной копией и перезапуском панели выполнено один раз.
Собственная тестовая модель сохранена в новый файл. Отдельная новая копия
результата открыта один раз; повторного создания системы координат не было.

Независимое чтение подтвердило сохранность тела на назначенном слое и системы
координат с заданными началом и осями. Активна мировая система, выделение пустое.
Проверены сохранённые файлы, отдельный checkpoint, журналы и отсутствие повтора.
Наблюдаемые свойства не являются доказательством полной топологической эквивалентности.

После реального сценария прошли 124 целевых теста без ошибок и пропусков.
Все четыре проверки GitHub исходного кода также прошли. Последующее изменение
этого отчёта затрагивает только документацию.

Подтверждена цепочка поздней проверки результата, получения свежей ссылки
на собственную копию, новой привязки, сохранения и открытия результата.
Проверка прежнего сохранённого результата не ослаблялась.

Следующий блок: явное переключение существующих систем координат и WORLD.
Общие К8–К11, матрица моделей и итоговая пользовательская приёмка остаются открытыми.
