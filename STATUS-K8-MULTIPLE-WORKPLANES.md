# К8: несколько систем координат — готовность ранней проверки

16 октября 2026. Native 0.37.0-dev / SDK 0.43.0-dev подготовлены в staging.
Установленный Bridge остаётся 0.36.0-dev. Новые CAD-команды не выполнялись.

Изменён существующий MCP путь активации: цель выбирается по свежей ссылке
конкретной WORKPLANE, а COG проверяется через два разных WORLD-базиса.
Проверяются все системы и WORLD-габариты тела; сохраняются один setter на intent,
отдельная независимая проверка, once/fence и запрет повторения неизвестного
результата. Отдельный режим чтения не получает инструментов активации.

Одна система сохраняет формат v1. Несколько систем используют формат v2.
Испытан переход от фактического старого Native 0.36 к новому verifier без
повтора setter; отдельно проверены исходные записи предыдущего реального
сценария. Исторический пакет не квалифицируется заново после изменения исходников.

До ранней реальной проверки прошли 23 native-случая, целевые SDK-проверки
активации и диагностики, SDK/native STDIO с переключением между двумя из трёх
систем, переподключение и независимый файловый аудит. Потеря ответа и отмена
после имитированного перехода между разными системами сохраняют журнал,
достигнутый контекст и блокировку, без повторной команды и автоматического WORLD.

Сценарий в PowerShape ещё требует отдельного разрешения: добавить одну систему
в собственной тестовой копии, независимо проверить создание и выполнить
отдельные проверяемые переключения существующая → новая → WORLD.
Сохранение, открытие файлов и преобразование тела в этот сценарий не входят.

Пассивное чтение подтвердило исходные условия: собственная копия, одна SOLID
на Surfaces, одна WORKPLANE, WORLD, пустое выделение и девять окон.
Полная регрессия и CI следуют после завершённого реального блока.
К8–К11 и матрица пяти классов остаются открытыми.
