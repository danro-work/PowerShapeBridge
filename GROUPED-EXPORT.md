# Экспорт контуров по исходному слою — P2.17

Один итоговый DGK содержит все контуры сечения рабочих поверхностей одного исходного слоя, на всех рассчитанных высотах. Высота Z не является ключом группировки.

Пример: исходный слой `1:Vneshnie 0.6` → файл `1-Vneshnie 0.6.dgk`. Двоеточия заменяются дефисами; пробелы и остальная часть имени сохраняются. Разные исходные слои получают разные файлы. Недопустимые имена Windows и конфликтующие имена файлов прекращают экспорт, без молчаливого переименования.

Промежуточные DGK по отдельным высотам нужны только для квалификации и восстановления. В итоговую папку выдаются общие файлы групп, без промежуточных файлов по Z.

## Реализация и границы

- `group_job.py`: группировка по `sourceLevel`, проверка источников и журналов, последовательное исполнение фаз, итоговая выдача.
- `GroupedExport.cs`: квалифицированное исполнение в установленном PowerShape 23.2.2. Исходные документы и ранее проверенные файлы защищены хешами. Каждое дополнение группы выполняется на новой копии, сохраняется и закрывается; полная группа экспортируется одним выделением всех её контуров.
- Итоговый DGK импортируется целиком. Затем все кривые проверяются на независимых копиях сохранённого импортированного проекта. Проверка разбита на небольшие порции из-за ограничения времени одного вызова панели.
- Вызов `slice_job.py --execute` после нарезки автоматически запускает общий экспорт; по умолчанию итоговая папка — `job-directory/DGK`. Можно задать `--grouped-output`.
- Отдельный `group_job.py` позволяет собрать уже проверенное задание без повторной нарезки. Он принимает `--bridge-root`, `--source-job`, `--output`, `--execute`.
- При неизвестном результате журнал сохраняется, фаза автоматически не повторяется. Повтор завершённой фазы также запрещён.

Текущая проверка ограничена эталонным кубом и его исходным слоем `0:General`. Общая функция группировки поддерживает разные имена слоёв, но исполнитель пока не допускает произвольную производственную геометрию. Выбор реальных рабочих поверхностей, привязка контуров к их исходным слоям, очистка и допуск отклонения требуют отдельной квалификации. Тест куба не подтверждает готовность всей ТМ.

Активная панель находится в `releases/P2.6`; worker обновляется отдельно. Корневой `PSBridge.exe` — историческая диагностика P0. Для запуска действующей панели используйте `Start-P2.6.cmd`. Изменение worker не обновляет заголовок уже открытой панели.
