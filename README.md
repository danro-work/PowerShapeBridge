## Исторический прототип P0

Целевая версия: PowerShape 23.2.2.0. Приложение Windows x64, .NET Framework 4.8+. VS Code достаточен для редактирования; .NET SDK и Visual Studio не нужны для этой сборки.

## Запуск

Оставьте в PowerShape открытым сохраненный проект `D:\ChatGPT\PowerShapeBridge\Test_Projects\Test_Block.psmodel`. Запустите `PSBridge.exe` и нажмите «Проверить подключение». Отчет автоматически записывается в `reports`.

Для диагностики без панели: `powershell -File .\probe.ps1`. Сборка: `powershell -File .\build.ps1`. Проверка внутренних функций: `PSBridge.Worker.exe --self-test`.

## Реализовано

- Строгое подключение к зарегистрированному открытому COM-объекту; новый PowerShape не запускается.
- Проверка PID, версии и полного пути активного проекта. Несовпадение прекращает чтение.
- `GetModelItems`/`GetItemData`: нативные типы/ID, имена, описания и слои; неизвестные типы сохраняются как UNKNOWN.
- Чтение занятых объектами слоев и базиса ЛСК; дополнительные значения сохраняются как raw, без предположений об единицах и точности.
- Сравнение исходных файлов по SHA-256, числа выделенных объектов и активной ЛСК до/после чтения.
- Отдельный STA worker, предел времени в панели/скрипте, журнал JSON и сообщения HRESULT. При timeout прекращается только worker Bridge.

## Границы

Это первый диагностический прототип, а не готовый агент. В нем нет записи/изменения геометрии, screenshot, габаритов, нарезки, DGK и сервера MCP. Нет вызовов Exec, Save, Select, Quit или конструктора API Autodesk. Библиотеки Autodesk будут подключены после квалификации базового канала.

Проверка счетчика selection не доказывает неизменность полного выбора; дисковые хеши не доказывают неизменность всей несохраненной геометрии. Чтение скрытых/неактивных сущностей нужно квалифицировать отдельно. `succeeded_verified` означает только проверки, перечисленные в `verificationScope` отчета.

COM использует регистрацию Windows: при нескольких запущенных PowerShape возможна неоднозначность. Прототип не переключает модель и отказывается читать другой проект. Для P0 используйте один экземпляр; полноценный выбор экземпляра — следующий этап.

Если получен `0x800401E3`/ActiveX 429 из ограниченной среды, запустите ту же проверку непосредственно в своем Windows-сеансе. Это не доказывает неисправность PowerShape и не требует его переустановки или постоянного запуска от администратора.

Схемы чтения взяты из официальных исходников Autodesk, commit `f0761e50ae833e7647423b8da3ba24bfc23bd93d`: PSAutomation, PSModel.InitialiseFast, PSEntityFactory, PSWorkplane. Поведение на установленном продукте подтверждается только успешным отчетом.
